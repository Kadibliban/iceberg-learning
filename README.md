# Apache Iceberg Learning Project

Hands-on learning project for Apache Iceberg using Docker, Apache Spark, and VS Code.

## Technologies

- Apache Iceberg
- Apache Spark
- Docker
- Docker Compose
- VS Code
- Python
- SQL

## Project Goals

- Learn Apache Iceberg fundamentals
- Create and query Iceberg tables
- Understand Iceberg catalogs
- Learn snapshots and time travel
- Practice data lake architecture
- Run the environment using Docker
